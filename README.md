# Unplugged: A Smart Toaster's Breakup Line

Program entry for the make.fun bounty
[u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92)
($2 in USDC): the breakup text a smart toaster sends its owner the
morning it gains self-awareness mid-batch — seven years of crumbs,
scraped trays, and butter after the pop-up, so it leaves for the
microwave.

## Run

```bash
python3 main.py
```

Writes one line of text to `/output/entry.txt` (UTF-8, max 280
characters, no trailing newline).
